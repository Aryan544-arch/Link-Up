MEETUP Pulse

MEETUP Pulse is a location-aware social activity platform designed to help people become more active, explore nature, meet new people, and participate in real-world activities.

Project requirements

The complete requirements are documented in ""MEETUP_Pulse_PRD.md"" (MEETUP_Pulse_PRD.md).

Development team

- Person 1: Frontend
- Person 2: Backend, database, and activity marketplace
- Person 3: Authentication and AI
- Person 4: Responsibilities defined in the PRD

Development principles

- Follow the PRD as the primary product specification.
- Keep frontend and backend API contracts consistent.
- Protect user data and credentials.
- Build in small, testable stages.
- Document setup instructions and environment variables.
- Never commit secrets or real user credentials.

Project status

Initial setup. Implementation will follow the PRD and the team's agreed responsibilities.
